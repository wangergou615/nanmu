# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately before public disclosure.

## Security Considerations

Nanmu AI Workspace may include AI-assisted workflows and automation components. Future features may interact with files, APIs, external services, or developer tools.

Security areas of focus include:

- Credential and API key protection
- Safe tool execution
- Dependency security
- Prompt injection prevention
- Secure handling of external inputs

## Development Practices

Security reviews, dependency updates, and careful evaluation of automation capabilities are part of the project's maintenance process.
